# 📊 Excel Sales Analysis Dashboards

A collection of interactive sales analysis dashboards built using Microsoft Excel to transform raw data into meaningful business insights through data analysis, KPI tracking, and data visualization.

## 📁 Projects Overview

### ☕ 1. Coffee Shop Sales Analysis

An interactive dashboard designed to analyze coffee shop sales performance and explore sales patterns across products, categories, store locations, and time periods.

**Key Analysis:**
- Sales performance and revenue trends.
- Total orders and quantity sold.
- Top-performing products and categories.
- Sales distribution by store location.
- Sales patterns by day of the week.
- Peak sales periods.

### 🍪 2. Biscuits & Cookies Sales Performance

An interactive dashboard focused on analyzing biscuits and cookies sales, profitability, and customer purchasing patterns.

**Key Analysis:**
- Revenue and profit performance.
- Profit margin tracking.
- Sales analysis across customer age groups and locations.
- Revenue distribution by gender.
- Sales analysis by payment method and price range.
- Performance monitoring through key performance indicators (KPIs).

## 🛠️ Tools & Techniques

- **Microsoft Excel** — Data analysis and dashboard development.
- **Pivot Tables** — Data summarization and aggregation.
- **Pivot Charts** — Visual representation of sales trends and comparisons.
- **Slicers** — Interactive filtering and dashboard exploration.
- **KPI Tracking** — Monitoring key business performance metrics.
- **Data Visualization** — Presenting data in a clear and business-friendly format.

## ✨ Key Features

- Interactive dashboards with slicer-based filtering.
- Visual summaries of key sales and profitability metrics.
- Product, category, customer, and location analysis.
- Multiple chart types for exploring patterns and trends.
- Excel workbooks containing the datasets, analysis, and dashboards.
